22. **Task - Context menu stays open after a click away** (v1.0.26): reported by the Star Colonel after the 1.0.26 install; traced to JupyterLab core, not this extension<br>
    **Result**: Investigation run `wf_a6963981-41e` (`tmp/workflows/investigate/context-menu.mjs`, reproduction `repro.mjs`) on isolated test servers, verifier CONFIRMED on fresh servers. The menu stays open only when the click lands inside an iframe - in the Star Colonel's workspace the HTML viewer beside the notebook; every other target closes it. Cause: a Lumino `Menu` closes only from a capture `pointerdown` listener on the top-level document (`@lumino/widgets` `menu.ts:539`, `822-838`), and a press inside an iframe goes to the iframe's own document; Escape fails too because focus moves into the iframe. Same result with this extension disabled and with all 71 third-party extensions disabled, so no bisection was needed. The defect goes into `docs/defects.md` rejected as a JupyterLab core issue; a fix belongs upstream in Lumino or in the advanced HTML viewer, which could forward iframe presses to the parent document.
